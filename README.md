# OpenWise

**Учись проектировать программы, пока Codex пишет код.**

OpenWise — скилл для Codex. Он возвращает пользователю инженерные решения: сначала ты объясняешь желаемое поведение и предлагаешь подход, затем Codex помогает разобраться, реализует согласованный небольшой шаг и проверяет его.

Это готовая адаптация для Codex, а не браузерное расширение. Скилл задаёт стиль работы агента; он не является технической блокировкой записи файлов и не гарантирует обучение.

## Установка

Для установки в отдельный проект выполни из папки проекта:

```sh
mkdir -p .agents/skills
git clone https://github.com/mmlvc/open-wise.git .agents/skills/open-wise
```

Папка назначения должна отсутствовать. Для доступа во всех проектах можно вместо этого клонировать репозиторий в `~/.agents/skills/open-wise`. Расположение и вызов соответствуют [официальной документации](https://learn.chatgpt.com/docs/build-skills). Если скилл не появился, перезапусти Codex. Не устанавливай одну копию одновременно в глобальную и проектную папки.

В новом чате:

```text
$open-wise Хочу сделать упрощённую копию Notion для обучения.
Помогай мне принимать инженерные решения, а код пиши сам.
```

## Как работает

1. Определяем минимальное полезное поведение.
2. Codex задаёт один открытый вопрос и ждёт твоего рассуждения.
3. Если понятие незнакомо, объясняет его, даёт подсказку или пример.
4. Фиксируем решение и компромиссы.
5. Codex реализует согласованный шаг, проверяет и объясняет важный механизм.

Например: «Что должно произойти с заметками, если удалить папку?» Затем: «Как представить это поведение в данных?» Решение не подменяется кнопкой «рекомендуется».

## Управление

Можно писать по-русски:

| Запрос | Действие |
| --- | --- |
| Дай подсказку | Небольшая подсказка к текущему вопросу |
| Объясни | Объяснение понятия с примером |
| Предложи варианты | Сравнение нескольких подходов |
| Просто реализуй этот шаг | Пропуск учебного обсуждения указанного шага |
| Приостанови обучение | Обычная разработка |
| Продолжи обучение | Возврат к сохранённому вопросу |
| Покажи прогресс | Решения, наблюдаемое понимание и следующий шаг |
| Сбрось обучение | Резервная копия заметок и новый учебный профиль |

Заметки хранятся в `.open-wise/` **рабочего проекта**: `profile.md`, `progress.md`, `project-map.md`. Возобновляй работу через `$open-wise`; автоматическое включение в каждом новом чате не обещается. Не коммить личные учебные заметки; при необходимости попроси Codex добавить `.open-wise/` в `.gitignore` проекта.
